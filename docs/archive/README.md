# Archived briefs, loop-prompts and reports

Every round brief, phase loop-prompt and phase report the project has produced,
kept in full rather than summarised.

**They are the record of what was asked for, not of what is true now.** A brief
states the world as it was understood on the day it was written, and several of
them were superseded by their own results — the raid diagnosis that was right
about the cause and wrong about the cure, the §6 prediction that was falsified,
the seed-99 hypothesis that failed. Read them for what was searched for and why,
and read `../WORLDBUILDER-PROJECT.md` for what the project currently holds to
be true.

That distinction is the reason these are archived rather than deleted. Revisions
supersede rather than replace: each report is left standing, because the earlier
one is still the record of what was looked for. Figures quoted inside them go
stale by design and are not authoritative — the manifest of a baseline is
authoritative over any count restated in prose, including in here.

**Still live, in `../`:**

- `WORLDBUILDER-PROJECT.md` — the standing reference.
- `phase-controls-and-seal.md` — the current phase.
- `phase-explain-decide-seal-prereg.md` — a pre-registration the current phase
  amends and then spends. It stays out of the archive until it has been used.
